Academic Formulations & Step-by-Step Derivations Reference (College Demonstration)
1. Logistic Regression Sigmoid & Logit
P(Y=1|X) = 1 / (1 + e^-z), where z = β₀ + ∑ βⱼXⱼ

Linearization: ln(p / (1-p)) = β₀ + β₁X₁ + ... + βₚXₚ

2. Accuracy Formulation
Accuracy = (TP + TN) / Total = (209 + 926) / 1,409 = 80.55%

Total verified test set correctly classified: 1,135 of 1,409 records.

3. Precision Formulation
Precision = TP / (TP + FP) = 209 / (209 + 109) = 209 / 318 = 65.72%

65.72% of customers flagged by model actually intended to churn.

4. Recall (Sensitivity) Formulation
Recall = TP / (TP + FN) = 209 / (209 + 165) = 209 / 374 = 55.88%

Captures 55.88% of all true churners in holdout evaluation.

5. F1-Score (Harmonic Mean)
F1 = 2 × (Precision × Recall) / (Precision + Recall) = 60.40%

Harmonic mean balancing precision and recall across decision boundaries.

6. Expected Loss Formulation
E[Loss] = ∑ (P_i × Charges_i) = $139,980.72 / month

Probability-weighted expected loss directly mirrors actual lost monthly charges ($139,130.85).
